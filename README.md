# DARK WEB — Digital Products Store

A professional mobile-friendly digital products e-commerce website powered by Node.js, Express, SQLite, and M-Pesa/Binance payment options.

## Features

- 🛒 Digital product store
- 👤 Customer registration and login
- 🔐 Admin dashboard
- ➕ Add products from phone
- 🖼️ Product image upload and preview
- ✏️ Product descriptions and pricing
- 🇰🇪 M-Pesa STK Push
- ₿ Binance / USDT payment submission
- 📦 Order tracking
- 📧 Email delivery option
- 📱 WhatsApp delivery option
- 🔎 Order status tracking
- 👨‍💼 Admin order management
- ✅ M-Pesa callback payment confirmation
- 🔐 Admin Binance payment verification
- 📱 Mobile responsive design
